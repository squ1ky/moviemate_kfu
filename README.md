# Фильмотека (Проектная практика ОРПУД 2024/25 КФУ)

Фильмотека - это веб-приложение для любителей кино и сериалов, предоставляющее возможность просматривать каталог фильмов, оставлять отзывы, создавать списки "Буду смотреть" и "Любимое" и получать персонализированные рекомендации на основе предпочтений пользователя.

## Функциональность

- Регистрация и авторизация: создание аккаунта и вход в систему
- Каталог фильмов и сериалов: просмотр и фильтрация по различным параметрам
- Детальная информация о фильмах: описание, жанры, актеры, режиссеры
- Профиль пользователя: статистика оценок, любимые жанры, топ фильмов
- Отзывы и оценки: возможность оставлять отзывы и оценивать фильмы по шкале от 1 до 10
- Список "Буду смотреть": сохранение фильмов для будущего просмотра
- Персональные рекомендации: получение рекомендаций фильмов и сериалов на основе предпочтений


## Технологии

- Python 3.12
- Django 5.2
- PostgreSQL
- HTML, CSS, JavaScript


## Структура проекта

Проект состоит из нескольких Django-приложений:

- auth_service: регистрация, авторизация и управление пользователями
- movie_service: управление фильмами, сериалами, отзывами и связанной информацией
- user_service: профили пользователей, статистика и персональные списки
- recommendation_service: система рекомендаций фильмов и сериалов

## Установка и запуск

Предварительные требования

- Python 3.8+
- PostgreSQL
- pip

### Шаги установки

1. Клонируйте репозиторий
```bash
git clone https://github.com/squ1ky/moviemate_kfu.git
cd moviemate_kfu
```
2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/Mac
venv\Scripts\activate     # Для Windows
```
3. Установите зависимости
```bash
pip install -r requirements.txt
```
4. Создайте файл .env в корневой директории проекта и укажите настройки базы данных:
```bash
DB_NAME=moviemate_kfu
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```
5. Примените миграции:
```bash
python manage.py migrate
```
6. Запустите сервер:
```bash
python manage.py runserver
```
7. Откройте браузер и перейдите по адресу http://127.0.0.1:8000/
